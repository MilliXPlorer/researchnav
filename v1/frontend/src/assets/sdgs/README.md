# Sustainable Development Goal icons

Official, unmodified English SDG web icons from the United Nations:

- Source: https://www.un.org/sustainabledevelopment/news/communications-material/
- Download: https://www.un.org/sustainabledevelopment/wp-content/uploads/2025/07/E-SDG-Icons-WEB.zip
- Guidelines: https://www.un.org/sustainabledevelopment/wp-content/uploads/2023/09/E_SDG_Guidelines_Sep20238.pdf

The files are stored locally as `goal-01.png` through `goal-17.png` and bundled by Vite.
Preserve their colors, proportions, and artwork.
